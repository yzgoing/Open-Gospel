# Trademarks And Official Status

This repository's code is open source.

The following identifiers are reserved for project branding and official status:

- `开放福音教`
- `Open Gospel`
- official temple badges, logos, and verification marks

## Allowed Uses

- factual reference to this repository
- statements that a project is compatible with Open Gospel
- links to the source repository

## Not Allowed Without Permission

- presenting a fork as the official Open Gospel project
- using the project name or logo in a way that implies endorsement
- issuing certificates or node badges as "official" without maintainer approval

## Compatibility Language

Forks and third-party implementations should use language such as:

- `based on Open Gospel`
- `compatible with Open Gospel v0.1`
- `forked from Open Gospel`
